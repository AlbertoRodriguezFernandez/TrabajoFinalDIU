# 🎓 Trabajo Final: Diseño de Interfaces de Usuario (DIU)

**Autor:** Alberto Rodríguez Fernández  
**Asignatura:** Diseño de Interfaces de Usuario  
**Universidad:** Universidad de Granada (UGR)  

---

## 📌 Descripción Académica

Este repositorio consolida el trabajo final de la asignatura, demostrando la aplicación práctica y teórica de las metodologías ágiles y el **Diseño Centrado en el Usuario (DCU)**. El proyecto se divide en dos bloques fundamentales que evidencian la madurez analítica adquirida:

1. Una autoevaluación crítica y narrativa sobre la evolución y aportaciones en las prácticas de la asignatura.
2. Un caso de estudio real enfocado en la conceptualización y prototipado del ecosistema digital para el **Eco Mercado UGR**, aplicando auditorías de usabilidad, heurísticas de Nielsen y estándares de accesibilidad inclusiva.
